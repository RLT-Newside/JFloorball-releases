# JFloorball

3D floorball (unihockey) for Android — IFF 3v3 rules and an Ultimate-Team style card mode.

## Download

Get the latest APK from **[Releases](../../releases/latest)**.

1. Open the `JFloorball-<version>.apk` link on your Android phone (64-bit, Android 7.1+).
2. Allow installs from your browser when Android asks, then install.
3. Updates install over the old version and keep your save.

Each release lists the SHA-256 of its APK.

The source code is private; this repository only hosts builds.
